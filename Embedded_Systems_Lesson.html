Learning Outcomes

  • Define an embedded system.
  • Explain the Sense → Process → Actuate cycle.
  • Identify common sensors and actuators.
  • Create a model of an embedded system.

Definition

An embedded system is a dedicated computer system built into a larger mechanical or electrical system to perform a specific function.
